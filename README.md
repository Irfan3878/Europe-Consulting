Explanation (English)

Web application built with Python and Flask, with a focus on secure development practices. Security features implemented:
• Password hashing, so user passwords are never stored in plain text
• User authentication and session management with Flask-Login
• SQL injection mitigation through parameterized ORM queries
• XSS protection through Jinja2 automatic HTML escaping

Source code available on GitHub.

Açıklama (Türkçe)

Python ve Flask ile geliştirdiğim, güvenli yazılım geliştirme pratiklerine odaklanan bir web uygulaması. Uygulanan güvenlik önlemleri:
• Şifre hashleme: kullanıcı şifreleri düz metin olarak saklanmıyor
• Flask-Login ile kullanıcı doğrulama ve oturum yönetimi
• Parametreli ORM sorgularıyla SQL injection riskinin azaltılması
• Jinja2 otomatik HTML escaping ile XSS koruması

Kaynak kod GitHub’da mevcut.
